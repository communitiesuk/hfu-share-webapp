You can only select one. If you need to select more you will need to start a new data access request for each area.

If you are from a unitary authority you can select either LTLA or UTLA for the relevant area you need to access to.

UTLA users only need to select their relevant UTLA. They will also get access to the LTLA data for that area, they do not need to submit another data access request for LTLA data.
